# Data Analytics - Level 1 Task 1: Exploratory Data Analysis on Retail Sales

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to extract meaningful insights regarding customer demographic behavior, sales trends, and product purchasing patterns.

## Objectives
- Perform data cleaning and handle missing values.
- Analyze key summary statistics (Mean, Median, Mode, Standard Deviation).
- Explore sales trends over time using time-series analysis.
- Identify top-selling product categories and customer demographics.

## Tech Stack & Tools
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## How to Run
1. Open the Jupyter Notebook file `OIBSIPDataAnalytics-L1-Task1-EDAretailsales.ipynb`.
2. Run all cells sequentially to view the analysis and data visualizations.
